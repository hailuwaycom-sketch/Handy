## 3. Tipografía

**Familia principal:** Inter (sans-serif)
- Peso 400: texto de cuerpo
- Peso 500: subtítulos / labels
- Peso 600: títulos secundarios (H2/H3)
- Peso 700: títulos principales (H1)

**Familia secundaria:** JetBrains Mono (monoespaciada)
- Uso reservado para badges, tags, métricas y elementos que refuercen el carácter técnico/agéntico de la marca

### Escala tipográfica sugerida (base 16px)

| Elemento | Fuente | Peso | Tamaño |
|---|---|---|---|
| H1 | Inter | 700 | 32–40px |
| H2 | Inter | 600 | 24–28px |
| H3 / subtítulos | Inter | 600 | 18–20px |
| Cuerpo de texto | Inter | 400 | 15–16px (line-height 1.5–1.6) |
| Labels / badges / datos técnicos | JetBrains Mono | 500 | 12–13px (letter-spacing 0.02em, mayúsculas) |

## 4. Combinaciones de contraste recomendadas

- Fondo #0A0D0C + texto #F2F6F4 → uso general, alto contraste (AA/AAA)
- Fondo #0A0D0C + acento #F0B848 → CTAs, íconos activos, links
- Fondo #183820 + texto #F2F6F4 → tarjetas o secciones secundarias

**Evitar:** usar el dorado #F0B848 como fondo extenso con texto oscuro encima. Funciona mejor como acento puntual, replicando su propio uso en la corona (símbolo, no superficie).

## 5. Concepto de marca

Oscuridad "imperial" (negro-verdoso) como base, dorado como sello de estatus y logro, Inter como voz clara y moderna para la comunicación, y JetBrains Mono como guiño constante a la identidad "agéntico / IA" de la marca.
