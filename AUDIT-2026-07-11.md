## 🟡 Media prioridad

- **[Seguridad]** CSP deshabilitado (`"csp": null`) en `src-tauri/tauri.conf.json:` bloque `security`.
  - **Impacto:** sin CSP, si en el futuro se introdujera cualquier vector XSS en el webview (dependencia comprometida, contenido no confiable renderizado), el atacante tendría vía libre para invocar comandos Tauri desde JS — incluyendo `change_external_script_path_setting` + el flujo de pegado (`src-tauri/src/clipboard.rs:505-511`), que ejecuta un binario local arbitrario con el texto dictado como argumento. Hoy no existe ese XSS (no se encontró `dangerouslySetInnerHTML`/`innerHTML` en `src/`), así que es defensa en profundidad, no una vulnerabilidad activa.
  - **Fix:** definir una CSP explícita en `tauri.conf.json` (`security.csp`), aunque sea permisiva al inicio (`default-src 'self'; script-src 'self'`), en vez de `null`.

- **[Seguridad]** API keys de proveedores de IA en texto plano en disco — `src-tauri/src/settings.rs:317` (`SecretMap`, `#[serde(transparent)]`) se serializa igual que un `HashMap<String,String>` normal al persistir `settings.json`. El `Debug` de `SecretMap` sí redacta (`src-tauri/src/settings.rs:319-328`, con test dedicado `debug_output_redacts_api_keys`), pero eso solo protege logs, no el archivo en disco.
  - **Impacto:** cualquier proceso o usuario con acceso de lectura al perfil de la app (`$APPDATA`) puede leer las API keys de OpenRouter/OpenAI/etc. en claro. Riesgo bajo-medio: requiere acceso local ya autenticado como ese usuario de Windows (mismo trust boundary que cualquier app de escritorio que no usa keychain), pero es evitable.
  - **Fix:** mover `post_process_api_keys` al credential manager del SO (crate `keyring` — ya soporta Windows Credential Manager / macOS Keychain / Secret Service en Linux) en vez de `settings.json` plano.

## 🎯 Top fixes (priorizados por impacto)

### 1. Definir una CSP en tauri.conf.json

**Archivo:** `src-tauri/tauri.conf.json` (bloque `security.csp`) · **Dimensión:** Seguridad · **Severidad:** media
**Acción:** reemplazar `"csp": null` por una política explícita, aunque sea de partida (`default-src 'self'`), y ajustar según lo que la webview realmente necesite cargar.

### 2. Mover las API keys de IA al credential manager del SO

**Archivo:** `src-tauri/src/settings.rs:317` (`SecretMap`) + su punto de persistencia (`write_settings`, línea ~1144) · **Dimensión:** Seguridad · **Severidad:** media
**Acción:** integrar el crate `keyring` para `post_process_api_keys`; mantener solo un identificador/flag en `settings.json`, no el valor real.

### 3. Meta tags Open Graph en la landing

**Archivo:** `landing/index.html:6-8` · **Dimensión:** Calidad Web · **Severidad:** media
**Acción:** agregar `og:title`, `og:description`, `og:image`, `twitter:card` antes de compartir el link del lanzamiento.
